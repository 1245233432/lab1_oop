cin.clear(); - сброс флага ошибки потока ввода (например, если ожидалось int, а ввели string, то поток ввода переходит в состояние ошибки (флаг ошибки был 0, а стал 1) - cin.fail() - и при текущем запуске программы этот поток уже не считает никакие символы)
srand(static_cast<unsigned int>(time(nullptr))); - static_cast - приведение типа в момент компиляции, приводит время в секундах в 32-битное беззнаковое целое число
cin.ignore(numeric_limits<streamsize>::max(), '\n'); - удаление всех символов из потока ввода. numeric_limits - это спец класс из библиотеки limits, который содержит всю инфу о границах числовых типов данных; <streamsize> - тип данных, который используется ТОЛЬКО для подсчета размера данных в потоках ввода-вывода (по сути псевдоним типа long long); max() - функция, которая возвращает самое большое число, которое может поместиться в указанный тип (т.е. streamsize)

r1 = static_cast<double>(rand()) - приведение случайного целого числа к типу дабл (static_cast обеспечивает принудительное приведение типов), чтобы далее делилось дабл на инт (по правилам C++ в таком случае делитель из инта переведется в дабл и получится в итоге дабл)
